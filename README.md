# AdGuard Lite

가벼운 Chrome 광고 차단 확장 프로그램입니다. 네트워크 차단은 브라우저의 정적 Declarative Net Request 규칙으로 처리하고, DOM 필터는 처음 한 번 전체를 확인한 뒤 추가·변경된 노드만 검사합니다.

## 기능
- 선언형 규칙으로 광고 네트워크 요청 차단
- DOM 변경분만 검사해 광고 요소 숨김
- 확장 프로그램 팝업에서 차단 기능 상태 표시
- 로컬 정적 보안 검사 도구

## 설치
1. Chrome에서 `chrome://extensions/`로 이동
2. `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램 로드`를 선택합니다.
4. 저장소 폴더를 선택합니다.

## 보안 검사
Node.js가 설치된 상태에서 저장소 루트에서 실행하세요.

```bash
node security_check.js
```

검사 도구는 외부 네트워크에 접속하지 않습니다. 정적 휴리스틱 검사이므로 결과를 직접 검토해야 하며 취약점이 없음을 보장하지 않습니다.

## 주요 파일
- `manifest.json` — 확장 프로그램 및 정적 규칙 설정
- `rules.json` — 네트워크 차단 규칙
- `content.js` — 변경된 DOM 영역의 광고 요소 필터
- `popup.html` / `popup.css` — 간단한 상태 팝업
- `security_check.js` — 로컬 정적 보안 검사기

## 제한 사항
정적 네트워크 규칙으로 바꾸면서 요청별 차단 통계는 제거했습니다. Manifest V3에서는 일반 배포 확장 프로그램이 차단 이벤트를 임의로 모두 관찰할 수 없으므로, 정확하지 않은 카운터를 표시하지 않습니다. 차단 목록은 의도적으로 기본 규칙만 포함하며 모든 광고를 막는 것은 아닙니다.
